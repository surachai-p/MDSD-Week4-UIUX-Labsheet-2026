## 🧪 การทดลองที่ 3: แปลง Design เป็น Flutter Code

### วัตถุประสงค์
เขียน Flutter Widget จาก Design แอปพลิเคชัน **"Green Market"** ที่ออกแบบไว้ใน Figma

### องค์ประกอบที่ดำเนินการ
* 3.1 เตรียม Flutter Project (`week03_ui_lab`) และนำไฟล์ `theme.dart` เข้ามาใช้
* 3.2 ตั้งค่า Material 3 Theme ใน `main.dart`
* 3.3 วิเคราะห์ Design เป็น Widget Tree
* 3.4 สร้างไฟล์โครงสร้าง (`home_screen.dart`, `detail_screen.dart`, `item_card.dart`)
* 3.5-3.8 สร้าง Widget ต่าง ๆ ตามโค้ดที่กำหนด
