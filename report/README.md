## 📝 คำถามสรุปการเรียนรู้ (ตอบทุกข้อ)

**ข้อ 1:** Material 3 ต่างจาก Material 2 อย่างไรในด้าน Color System? 
> **คำตอบ :** Material 3 มีจุดเด่นเรื่อง Dynamic Color และระบบ Tonal Palettes โดยเราสามารถกำหนดสีหลัก เพียงสีเดียว ระบบจะคำนวณและสร้างเฉดสีที่เกี่ยวข้องให้อัตโนมัติ เพื่อให้ได้ชุดสีที่เข้ากันและมีค่า Contrast ที่เหมาะสมสำหรับการอ่าน ทั้งในโหมด Light และ Dark แตกต่างจาก Material 2 ที่นักพัฒนาหรือดีไซเนอร์จะต้องเป็นคนกำหนดค่าสี Primary และ Secondary ต่างๆ เองแบบ Manual

**ข้อ 2:** เมื่อแปลง Figma Design เป็น Flutter Widget พบปัญหาอะไรบ้าง และแก้ไขอย่างไร?
> **คำตอบ :** ปัญหาที่พบคือ การจัดระยะห่างและสัดส่วนหน้าจอ ใน Figma การใช้ Auto Layout จัดการระยะห่างได้ง่าย แต่เมื่อเขียนโค้ด Flutter ต้องแปลงแนวคิดนั้นมาใช้ Row, Column, Padding และ SizedBox ให้ถูกต้องแทน การแก้ไขคือต้องวิเคราะห์ Widget Tree ให้ชัดเจนก่อนลงมือเขียนโค้ด และใช้ Expanded หรือ Flexible เพื่อจัดการกับพื้นที่ว่าง ป้องกันปัญหาหน้าจอล้นเมื่อนำไปรันบนขนาดจอที่แตกต่างกัน

**ข้อ 3:** Code ที่ AI สร้างให้นั้นสมบูรณ์แค่ไหน? ต้องปรับปรุงอะไรบ้าง?
> **คำตอบ :** โค้ดที่ AI สร้างให้มีความสมบูรณ์ในแง่ของโครงสร้างพื้นฐานและการเรียกใช้ Theme ได้อย่างถูกต้องตรงตามที่สั่ง แต่ยังต้องปรับปรุงในส่วนของ การจัดการข้อผิดพลาดและ Best Practice บางจุด เช่น การแสดงผลรูปภาพ

**ข้อ 4:** ถ้าจะนำ UI ที่ออกแบบไปใช้กับ Project จริง จะปรับปรุงอะไรบ้าง?
> **คำตอบ :** สิ่งที่อยากจะปรับปรุงคือได้แก่ การจัดการสถานะ และ การรองรับหลายหน้าจอ
